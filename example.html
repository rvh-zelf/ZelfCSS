Body text uses a system font stack with text-wrap: pretty to prevent orphaned words. ZelfCSS styles standard HTML elements directly — no class names needed for the basics. Links are underlined by default for accessibility, and focus states are WCAG 2.2 AA compliant across all interactive elements.

Strong text for emphasis, italicised text for nuance, and small text for fine print. You can also use deleted text and inserted text.

A minimalist framework doesn't mean fewer features — it means fewer surprises. Style the elements. Trust the cascade. — ZelfCSS design principle

Inline code and a code block:

/* ZelfCSS — no class soup required */
h1, h2 {
  font-weight: 700;
  text-wrap: balance;
}

p {
  text-wrap: pretty;
}

Accessible hidden content

Use .sr-only or .visually-hidden to hide content visually while keeping it available to screen readers: 

<span class="sr-only">Skip to main content</span>
